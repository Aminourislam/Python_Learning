📊 Medical Records Validator — Workflow Diagram

Validation logic for patient records (freeCodeCamp workshop) — fixed Mermaid syntax

flowchart TD
    Start(["Start: validate(medical_records)"]) --> CheckSeq{Is data a list or tuple?}
    
    CheckSeq -->|No| PrintSeqErr["Print error: expected list/tuple"]
    PrintSeqErr --> ReturnFalse(["Return False"])
    
    CheckSeq -->|Yes| Init["Initialize: is_invalid = False, key_set = required keys"]
    
    Init --> ForEach["For each index, dictionary in enumerate(data)"]
    
    ForEach --> IsDict{Is it a dict?}
    IsDict -->|No| PrintDictErr["Print: expected dict at position {index}"]
    PrintDictErr --> SetInvalid1["is_invalid = True"]
    SetInvalid1 --> ContinueLoop["Continue to next record"]
    ContinueLoop --> ForEach
    
    IsDict -->|Yes| CheckKeys{Keys match key_set?}
    CheckKeys -->|No| PrintKeyErr["Print: missing/invalid keys at {index}"]
    PrintKeyErr --> SetInvalid2["is_invalid = True"]
    SetInvalid2 --> ContinueLoop
    
    CheckKeys -->|Yes| CallFind["Call find_invalid_records(**dictionary)"]
    
    CallFind --> GetInvalid["invalid_records = list of invalid keys"]
    GetInvalid --> ForEachKey["For each key in invalid_records"]
    
    ForEachKey --> PrintUnexpected["Print: Unexpected format 'key: value' at position {index}"]
    PrintUnexpected --> SetInvalid3["is_invalid = True"]
    SetInvalid3 --> NextKey["Next key"]
    NextKey --> ForEachKey
    
    ForEachKey --> AfterLoop["After processing all keys"]
    AfterLoop --> ContinueLoop
    
    ContinueLoop --> MoreRecords{More records?}
    MoreRecords -->|Yes| ForEach
    MoreRecords -->|No| CheckFinal{is_invalid == True?}
    
    CheckFinal -->|Yes| ReturnFalse2(["Return False"])
    CheckFinal -->|No| PrintValid["Print: Valid format."]
    PrintValid --> ReturnTrue(["Return True"])

⚙️ How the validator works: The diagram shows the complete flow — from checking input type, iterating records, validating keys, calling find_invalid_records (which checks patient_id format, age ≥18, gender, diagnosis, medications list, last_visit_id), printing specific error messages for each invalid field, and finally returning False if any record is invalid, otherwise True.
